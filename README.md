
# aAidea MitoKill Discovery Studio

A public-facing research-stage web demo for **FDG-PET-guided, mitochondria-targeted tumour-killing therapy**.

## Concept

Cancer often reveals metabolic vulnerability through FDG-PET glucose avidity. This demo models how FDG-PET metrics, glycolytic biomarkers, mitochondrial vulnerability, payload choice, safety gates, and development milestones could be integrated into a research-stage discovery framework.

## Modules

- Patient selection simulator

- FDG-PET metric modelling

- MitoKill Suitability Score

- Molecule design selector

- Payload comparison dashboard

- Safety-gate model

- Development roadmap

- Investor and philanthropy summary

## Candidate classes

- 2DG-PEG3-TPP-Ce6

- Glucose-PEG3-TPP-Ce6

- 2DG-PEG3-TPP-BODIPY

- 2DG-PEG3-TPP-Auger

- Glucose-decorated alpha-emitter carrier concept
